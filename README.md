# HKD Dewas QR Code

Website deployment guide.

## Hosting Platforms

- Vercel
- Netlify
- Cloudflare Pages

## GitHub Setup

1. Create a GitHub repository.
2. Upload the website source code.
3. Push all changes to the main branch.

## Vercel Deployment

1. Login to Vercel.
2. Import the GitHub repository.
3. Select the correct framework.
4. Configure the build settings according to the project.
5. Click Deploy.

## Netlify Deployment

1. Login to Netlify.
2. Add a new project.
3. Import the GitHub repository.
4. Configure the publish directory.
5. Deploy the website.

## Cloudflare Pages Deployment

1. Login to Cloudflare.
2. Open Workers & Pages.
3. Create a Pages project.
4. Connect the GitHub repository.
5. Configure the build settings.
6. Deploy.

## SEO

- robots.txt
- sitemap.xml
- Custom 404 page

after connecting the actual domain.
